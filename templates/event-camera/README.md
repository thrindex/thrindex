# Template: Event-Camera Vision (N-MNIST)

Demonstrates the full thrindex pipeline on
[Neuromorphic-MNIST (N-MNIST)](https://www.garrickorchard.com/datasets/n-mnist) —
the canonical event-camera classification benchmark.

**Reference:** Orchard et al. 2015 — "Converting Static Image Datasets to Spiking
Neuromorphic Datasets Using Saccades".
*Frontiers in Neuroscience*, 9, 437.
[DOI: 10.3389/fnins.2015.00437](https://doi.org/10.3389/fnins.2015.00437)

## Dataset

N-MNIST records handwritten digits from the MNIST test set using a Dynamic Vision
Sensor (DVS) camera executing three saccade movements.  Each sample produces
asynchronous ON/OFF events at 34 × 34 pixel resolution over a ~40 ms window.

| Property | Value |
|---|---|
| Sensor resolution | 34 × 34 px, 2 polarities |
| Train / test split | 60,000 / 10,000 |
| Classes | 10 (digits 0–9) |
| Avg. events per sample | ~3,000 |

Events are binned into **T = 20** equal-duration frames (2 ms each).
Each frame is a binary tensor `[2, 34, 34]` → flattened to **2312 features**.

## Architecture

```
Dense(2312 → 1024) → LIF(τ_mem=20ms)
Dense(1024 →  256) → LIF(τ_mem=20ms)
Dense( 256 →   10) → LIF(τ_mem=20ms)
```

- Input: 2312 features (2 polarities × 34 × 34 pixels), 20 timesteps
- Output: 10 classes
- Committed floor: **≥ 95.0%**

**Floor evidence (feedforward, no STDP, no recurrence):**

| Reference | Accuracy | Architecture |
|---|---|---|
| Orchard et al. 2015 ([doi](https://doi.org/10.3389/fnins.2015.00437)) | 97.8% | rate-coded feedforward SNN |
| Lee et al. 2016 (STDP excluded) | 98.7% | backprop SNN baseline |

Floor is set with conservative margin below the feedforward baseline (97.8%).
STDP-based and recurrent results (≥ 99%) are excluded as non-comparable.

## Full training

```bash
pip install thrindex tonic
python templates/event-camera/train.py --data-dir /tmp/nmnist --epochs 30
```

`tonic` downloads N-MNIST (~315 MB) automatically on first run.
Training for 30 epochs on a modern GPU takes roughly **8–12 minutes**.

| Flag | Default | Description |
|---|---|---|
| `--data-dir` | `/tmp/nmnist` | Dataset cache directory |
| `--epochs` | `30` | Training epochs |
| `--results-out` | `/tmp/nmnist_results.json` | JSON results path |

## Bundled samples

`samples/` contains three synthetic N-MNIST-shaped spike trains for fully offline
demos.  Each JSON encodes a `[T=20, 2312]` binary spike tensor and a label.

Generated by `_generate_samples.py` — realistic event sparsity (~1% per frame per
polarity), matching the published N-MNIST statistics.

## Pipeline

```python
import thrindex as thx
import thrindex.snn as snn

# Preprocess: bin events into frames, flatten spatial dimensions
# frames: [T=20, batch, 2, 34, 34] → [T, batch, 2312]

model = snn.Sequential(
    snn.Dense(2312, 1024),
    snn.LIF(threshold=0.5, tau_mem=20.0),
    snn.Dense(1024, 256),
    snn.LIF(threshold=0.5, tau_mem=20.0),
    snn.Dense(256, 10),
    snn.LIF(threshold=0.5, tau_mem=20.0),
)

# After training:
thx.compile(model, "model.thx")
```

Then from the terminal:

```bash
thrindex run model.thx --seed 0
```

## Encoder note

N-MNIST events arrive pre-encoded as sparse ON/OFF spikes — no additional encoder
is applied.  The `ToFrame` transform from `tonic` bins the event stream into
discrete timesteps and the spatial tensor is flattened before feeding the SNN.
Conv2d spatial feature extraction (Dense → Conv2d → LIF chains) is deferred to
a future template once the compiler's flatten lower-pass is complete.

## Energy estimate

`thrindex run` prints a modelled energy estimate per inference.
See [docs/energy.md](../../docs/energy.md) for the synaptic-operation cost model.

On a feedforward Dense SNN at ~1% firing rate:
- Dominant cost: Dense(2312 → 1024) ≈ 2,312 × sparsity × cost_per_SOP
- Event-native processing reduces computation by ~100× vs a frame-based CNN
  operating on dense 28×28 frames.
